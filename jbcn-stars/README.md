# JBCN Stars – Junior Level Practice Test

An original practice paper in the format of the 2023–2025 JBCN Stars Junior papers.

| File | Contents |
|---|---|
| `JBCN_Stars_Junior_Practice_Test.pdf` | Team Round (10 problems, 60 min) and Individual Round (30 MCQs, +4/−1, 60 min), each with a response sheet |
| `JBCN_Stars_Junior_Practice_Answer_Key.pdf` | Answers and worked solutions (keep separate from the student) |
| `practice-test.html`, `answer-key.html`, `style.css` | Sources for the PDFs |

To regenerate a PDF, print the HTML from Chrome or run headless Chromium with `--print-to-pdf`.
